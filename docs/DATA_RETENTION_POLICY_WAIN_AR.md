## 🎯 مقدمة

يلتزم تطبيق WAIN بقانون حماية البيانات الشخصية السعودي (PDPL) والمادة 7 بشأن **مدة الاحتفاظ بالبيانات الشخصية**.

تحدد هذه السياسة **المدة التي يحتفظ فيها WAIN بكل نوع من أنواع البيانات** بعد تجميعها أو معالجتها.

## 🔄 سياسة الحذف التلقائي

### 1. حذف بيانات الأغراض
```
- عند حذف غرض: حذف جميع الصور والبيانات المرتبطة فوراً
- عند حذف الحساب: حذف جميع الأغراض والبيانات فوراً
- إمكانية الاسترجاع: النسخ الاحتياطية للـ 30 يوم التالية فقط
```

### 2. حذف الوثائق المالية
```
الفواتير والإيصالات:
├─ بعد 5 سنوات: حذف الإيصالات تلقائياً
├─ بعد 7 سنوات: حذف الفواتير تلقائياً
└─ التنبيه: إرسال تذكير قبل الحذف بـ 30 يوم

الضمانات:
├─ بعد انتهاء فترة الضمان بـ 1 سنة: حذف تلقائي
└─ التنبيه: إرسال تذكير قبل انتهاء الضمان
```

### 3. حذف سجل التدقيق
```
سجل الوصول والأنشطة:
├─ بعد سنتين: حذف جميع سجلات الوصول تلقائياً
├─ الاحتفاظ: آخر سنتين فقط في قاعدة البيانات
└─ الأرشفة: نسخة مشفرة في الأرشيف لمدة سنة إضافية (بدون الوصول)
```

### 4. حذف النسخ الاحتياطية
```
النسخ الاحتياطية اليومية:
├─ بعد 30 يوماً: حذف تلقائي
├─ الاحتفاظ: آخر 30 يوم فقط متاح
└─ الهدف: السماح بالاسترجاع من الأخطاء العرضية
```

## 🛡️ معايير الحذف الآمن

### المعيار 1: الحذف الكامل
```
✅ الحذف من قاعدة البيانات الرئيسية
✅ حذف من النسخ الاحتياطية (بعد 30 يوم)
✅ حذف من ذاكرة التخزين المؤقت
✅ حذف من CDN إن وجد (الصور)
```

### المعيار 2: التشفير
```
- جميع البيانات مشفرة أثناء الجلوس (TLS في الانتقال)
- البيانات المحذوفة لا تُسترجع (permanent deletion)
- عدم ترك نسخ في السجلات غير الضرورية
```

### المعيار 3: الموافقة
```
قبل الحذف النهائي:
├─ إرسال تذكير للمستخدم (بريد إلكتروني)
├─ السماح بـ 7 أيام لتغيير الرأي
└─ بعد 7 أيام: حذف نهائي بدون استرجاع
```

## 🔐 معالجة طلبات الحذف

### طلب حذف من قبل المستخدم

```
1. التحقق:
   ├─ التحقق من الهوية عبر البريد الإلكتروني
   ├─ تأكيد الطلب من قبل المستخدم
   └─ توثيق الطلب مع الوقت والتاريخ

2. التنفيذ:
   ├─ حذف حساب المستخدم
   ├─ حذف جميع البيانات المرتبطة
   ├─ حذف سجل المصادقة
   ├─ حذف النسخ الاحتياطية بعد 30 يوم
   └─ توثيق اكتمال الحذف

3. الإشعار:
   ├─ إرسال تأكيد بالبريد الإلكتروني
   ├─ توثيق الطلب في سجل التدقيق
   └─ الاحتفاظ بسجل الطلب لمدة سنة واحدة
```

## 🚨 استثناءات قانونية

### الحالات التي لا تُحذف البيانات:

1. **الالتزام القانوني:**
   - أوامر قضائية صريحة
   - تحقيقات أمنية من جهات حكومية
   - متطلبات ضريبية سعودية (فواتير 7 سنوات)

2. **الأمان والقانون:**
   - اكتشاف احتيال/جريمة
   - منع الاستخدام السيء (إساءة الاستخدام)
   - حماية حقوق الآخرين

3. **الأغراض الإحصائية:**
   - بيانات مجهولة الهوية (بدون تحديد الشخص)
   - إحصائيات الاستخدام العامة

## 📞 حقوق المستخدم

### حق الوصول:
- المستخدم يستطيع طلب نسخة من بيانته في أي وقت
- الرد خلال **14 يوماً** من الطلب
- بصيغة قابلة للقراءة (PDF أو JSON)

### حق التصحيح:
- المستخدم يستطيع تصحيح بيانات حسابه
- التحديث فوري في قاعدة البيانات
- لا تُؤثر على البيانات المحذوفة بالفعل

### حق الحذف:
- المستخدم يستطيع طلب حذف حسابه وبيانته
- الحذف نهائي بدون استرجاع (بعد 7 أيام)
- توثيق الطلب والحذف

### حق النقل:
- المستخدم يستطيع الحصول على بيانته بصيغة معروفة
- سهلة النقل إلى خدمة أخرى
- بدون رسوم إضافية
