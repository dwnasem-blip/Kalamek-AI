# Kalamek AI 🎬

تطبيق ذكاء اصطناعي متكامل يحوّل الكلام المنطوق في الفيديو إلى نصوص مزامنة تلقائياً مع الصوت.

## المميزات الأساسية

- ✅ رفع الفيديو من الهاتف
- ✅ استخراج الكلام الآلي (Whisper API)
- ✅ دعم العربية والعالمية
- ✅ مزامنة النص مع الصوت (Word-level sync)
- ✅ مكتبة خطوط عربية ضخمة (100+)
- ✅ تعديل يدوي للنص والتوقيت
- ✅ تعرف على المتحدثين (Speaker Diarization)
- ✅ ترجمة
- ✅ تصدير بجودة عالية
- ✅ نظام اشتراكات

## البنية التقنية

- **Frontend**: React Native + Expo
- **Backend**: Supabase (PostgreSQL + Functions)
- **AI**: OpenAI Whisper API
- **Video Processing**: FFmpeg
- **Monetization**: RevenueCat
- **Storage**: Supabase Storage
